# Liubov Bakh Photography — приложение для учёта проектов фотостудии

Современное веб-приложение (фреймворк Next.js) с базой данных PostgreSQL для ведения проектов, заметок и статистики фотостудии.

## Что нужно для запуска
- Node.js 18+
- База данных PostgreSQL (строка подключения)

## Переменные окружения
Создайте файл `.env` (или задайте переменные на хостинге) по образцу из `.env.example`:

```
DATABASE_URL="postgresql://USER:PASSWORD@HOST:5432/DBNAME"
```

## Установка и запуск

```bash
# 1. Установить зависимости
yarn install        # или: npm install

# 2. Создать таблицы в базе данных и загрузить начальные данные (пакеты, цены)
yarn prisma generate
yarn prisma db push
yarn prisma db seed   # загрузит пакеты и цены (если есть scripts/seed)

# 3а. Запуск для разработки
yarn dev

# 3б. Запуск в продакшене
yarn build
yarn start
```

После запуска приложение будет доступно на http://localhost:3000

## Деплой на Railway / Render
1. Подключите этот репозиторий к сервису.
2. Добавьте базу данных PostgreSQL в том же проекте.
3. Задайте переменную окружения `DATABASE_URL` (ссылка на базу).
4. Команда сборки: `yarn prisma generate && yarn build`
   Команда запуска: `yarn start`
5. После первого деплоя один раз выполните `yarn prisma db push` (через консоль хостинга), чтобы создать таблицы.
